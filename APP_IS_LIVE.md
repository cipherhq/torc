## 🔧 Troubleshooting

### If You See White Screen:
1. **Hard Refresh**: `Cmd+Shift+R` (Mac) or `Ctrl+Shift+R` (Windows)
2. **Clear Cache**: DevTools → Empty Cache and Hard Reload
3. **Try Incognito**: Bypass extensions and cache

### If Page Won't Load:
1. Check the URL is exactly: `http://localhost:8080`
2. Make sure no VPN is blocking localhost
3. Try `http://127.0.0.1:8080` instead

### Console Warnings:
- Chrome extension errors → **Ignore them**
- Manifest warnings → **Harmless**
- Source map warnings → **Harmless**
