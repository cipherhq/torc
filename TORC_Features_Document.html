Resend API 7 Templates

create-payment-intent

Creates Stripe PaymentIntents for checkout. Gets/creates Stripe customer, attaches payment method, returns client secret for frontend confirmation.

Stripe PCI Compliant

Security: Row-Level Security (RLS)

All 23 tables have RLS enabled. Key policies:

  • Jobs: Users see own jobs; customers create; providers see pending; admins full access
  • Profiles: Anyone can view; self-update only; admins can update any
  • Documents: Providers manage own; admins manage all; public denied
  • Payments: Users manage own; service role processes
  • Support: Users see own tickets; admins manage all
  • Settings: Admins read/write; authenticated read public keys; anonymous read legal only

Email Architecture

Provider: Resend (https://resend.com/) • From: TORC <noreply@torcapp.com>
Method: Supabase Edge Function receives { to, template, data } → renders HTML template → calls Resend API
Error handling: All emails are fire-and-forget (non-blocking); errors logged but never block UI operations
Design: Consistent branded HTML layout with teal gradient header, card-based content, responsive design
